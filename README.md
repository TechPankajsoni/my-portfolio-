## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/pankaj-s-dev-hub.git
   cd pankaj-s-dev-hub
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the application.

### Build for Production

```bash
npm run build
# or
yarn build
```

The built files will be in the `dist/` directory.

## 🎨 Customization

### Personal Information
Update the following files to customize with your information:
- `src/components/HeroSection.tsx` - Update name, description, and profile photo
- `src/components/AboutSection.tsx` - Personal details and background
- `src/components/ExperienceSection.tsx` - Work experience
- `src/components/SkillsSection.tsx` - Technical skills
- `src/components/ProjectsSection.tsx` - Project portfolio
- `src/components/ContactSection.tsx` - Contact information

### Styling
- Colors and themes can be modified in `tailwind.config.ts`
- Custom CSS can be added to `src/App.css` or `src/index.css`
- Component styles are managed through Tailwind classes
